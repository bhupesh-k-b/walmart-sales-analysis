# Evidence-backed project description

**Walmart Sales Analysis | MySQL, SQL, Python**

- Built a MySQL pipeline for 421K+ weekly store-department sales observations across 45 Walmart stores and 81 departments, reconciling $6.74B in recorded sales to source totals.
- Used CTEs and window functions to compare store performance, sales per square foot, department rankings, holiday patterns, and week-over-week growth.
- Evaluated rolling weekly forecasting baselines on a 12-week holdout and generated reproducible reporting exports for planning analysis.

The records are weekly aggregates, not transactions. Do not claim city-level trends, peak operating hours, profitability, customer segmentation, or realized supply-chain improvements from this source.
